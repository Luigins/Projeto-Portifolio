# Meu Portfólio Pessoal

Este é um projeto de um portfólio web pessoal estático, construído para apresentação profissional, exibição de habilidades e contatos.

## 📁 Estrutura do Projeto

A estrutura de arquivos do projeto é bem simples e direta:

* **`portifolio.html`**: O arquivo principal que contém toda a estrutura da página web do portfólio.
* **`assents/`**: Diretório reservado para guardar os arquivos de mídia e recursos visuais do projeto.
  * **`Minha_foto.jpg`**: Arquivo de imagem com a foto de perfil utilizada no portfólio.

## 🚀 Como executar o projeto

Por ser um projeto web estático, a execução é extremamente simples e não requer a instalação de servidores ou dependências.

1. Faça o download da pasta do projeto para o seu computador.
2. Abra a pasta `Portifolio`.
3. Dê um duplo clique no arquivo **`portifolio.html`**.
4. O seu portfólio será aberto imediatamente no seu navegador web padrão (Google Chrome, Firefox, Edge, etc.).
